# Cricket Manager

Simple localhost game where you draft 11 real-world cricket players and simulate a T20 score.

## Run on localhost

```bash
python3 -m http.server 8080
```

Then open:

- http://localhost:8080

## Deploy to Vercel

This is a static site. You can drag-and-drop this folder into Vercel, or run:

```bash
npm i -g vercel
vercel
```
